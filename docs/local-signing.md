# Local macOS signing

Local packaging selects one installed **Apple Development** identity when available. With multiple identities, set `LEARNTRANSCRIBER_LOCAL_IDENTITY` to the exact certificate name; packaging rejects an unavailable or ambiguous choice. With no Apple Development identity, the existing `LearnTranscriber Dev` identity remains the fallback. Without either, the local package remains unsigned. A selected identity enables `forceCodeSigning`, so a signing failure does not silently produce an unsigned artifact.

Create or import the development certificate through Xcode's account and certificate management. See Apple's [certificate management guide](https://help.apple.com/xcode/mac/current/en.lproj/dev154b28f09.html) and [certificate overview](https://developer.apple.com/help/account/certificates/certificates-overview). The script does not create accounts, import private keys or change Keychain access controls. Keychain prompts depend on the installed key and its access settings; choosing a certificate alone is not proof that prompts disappear.

The installed electron-builder version is 26.15.3. Its `findIdentity` implementation rejects a `Developer ID Application:` prefix in the explicit qualifier, so release arguments remove that prefix after validating the complete installed identity. This behavior is verified against the installed `app-builder-lib/out/codeSign/macCodeSign.js`; see the [upstream source](https://github.com/electron-userland/electron-builder/blob/master/packages/app-builder-lib/src/codeSign/macCodeSign.ts). Release validation still requires the full Developer ID Application identity and an owned notarytool profile. A local override cannot replace those requirements.

Hardened rehearsals use the standard entitlements for Apple Development identities. Only the existing self-signed fallback uses the rehearsal entitlement that relaxes library validation. Public distribution still requires the separate Developer ID/notarization path; a local development signature is not public distribution. See [electron-builder's macOS documentation](https://www.electron.build/v26/docs/mac/).

This machine currently exposes only `LearnTranscriber Dev`. Its local bundle was built and verified with `codesign --verify --deep --strict`. Selection of an Apple-issued certificate is covered by tests but cannot be exercised until such an identity is installed.

# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub instead: open this repository's **Security** tab
and choose **Report a vulnerability**.

Include what is affected, the steps to reproduce it and what an attacker could do with it. Reports about the following
are especially useful:

- how API keys or the ChatGPT sign-in kept in the macOS Keychain could leak;
- how recordings or transcripts could leave the Mac without the person asking;
- how a web page or a model answer could reach the app's privileged bridge.
